# Vectora 矢量路径工具

安装：Node.js 22 环境下执行 `npm ci`。

本地启动：`npm run dev`，打开终端显示的地址。

Docker 启动：`docker compose up --build`，访问 http://localhost:8119。

## 几何约束

在画布上单击锚点进行拾取（Shift 单击加选，最多 4 个），然后在左侧
Constraints 面板添加约束：

- **⊙ Coincident**（2 个锚点）：两点重合
- **∿ Tangent**（2 个锚点）：两点重合且手柄共线，曲线平滑相接
- **↔ Dimension**（2 个锚点）：两点距离固定为指定尺寸，可在面板中直接改数值
- **＝ Equal**（4 个锚点）：两对点间距相等

行为约定：

- 约束可跨路径、跨编组；修改尺寸数值后相关曲线与面板读数同步更新。
- 属性面板的 **Fixed** 开关锁定形状：求解器与拖动都不会移动它。
- 拖动过程中是瞬时预览（底栏显示 residual），松开指针后才以高精度
  落定约束结果；多解情形保持当前分支，不会翻到另一侧。
- 约束过冲突时，冲突条目标红并显示 ⚠，图形保留上一个可用结果；
  删除约束不会移动图形。
- 约束随文档一起进入撤销/重做与本地存储；导出的 SVG 只包含求解后的
  实际路径，不含任何求解器状态。
